# aeolus-fleet-selfhost

This repository is the supported way to self-host an Aeolus fleet: one Docker Compose setup that runs every part of the fleet on your own machine or server.

It is being built now. Until it is ready, follow the self-hosting guidance in the Aeolus docs.

Self-host docs: https://aeolus-fleet.dev/docs/self-host/
