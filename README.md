# aeolus-fleet-selfhost

The supported way to self-host an Aeolus fleet: one Docker Compose setup that runs every part of the fleet on your own machine or server, from the published npm packages.

It is being built now. Until it is ready, follow the guides:

- [Self-host](https://github.com/ThomasHendrickx/aeolus-fleet/blob/main/docs/guide/self-host.md): from nothing to a running fleet, signed in as its operator.
- [Run the server](https://github.com/ThomasHendrickx/aeolus-fleet/blob/main/docs/guide/run-the-server.md): keep it running, upgrade, back up and restore.
